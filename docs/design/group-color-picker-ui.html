分组颜色选择器 · 交互设计稿 v1 · 2026-09-14

适用于三个入口：① 组头右键菜单「分组颜色」面板（点即生效） ② 新建分组对话框 ③ 编辑分组对话框（随「确定」提交）—— 同一套控件，三种语义。

设计要点

1
色格加大 + 圆角 32px 触摸目标

24×22px → 32×32px 圆角色格，点击容错翻倍；按色环顺序排布，同色系相邻，找色有规律。

2
选中态 = 勾选 ✓ + 同色外环

替代原先的白色描边：格内白勾 + 格外同色 ring，当前色一眼定位，扫视不费力。

3
「无颜色」升级为图标按钮

从纯文字描边按钮改为 🚫 图标 + 文案，与 hex 输入框并排一行，主次分明：色板为主、微调为辅。

4
头部当前色胶囊 + hex 只读展示

面板顶部显示当前色圆点与 hex 原文，改色立即反馈；hex 输入收进底部，普通用户不被打扰。

5
对话框内新增「实时预览条」

选色时同步渲染组头行（chevron / 文件夹 / 组名 / 计数徽章同色），所见即所得，不确定效果再确定提交。

6
chevron 跟随组色（已修复）

折叠箭头与文件夹图标统一染组色，无色时回落次级前景色——组头"身份区"颜色完整。

交互流程

1右键组头

弹出组头菜单；「分组颜色」项带当前色块，一眼看到现在的颜色。

2点「分组颜色」

菜单保持打开，取色面板贴菜单右缘弹出（放不下自动翻左侧）。

3点色格 / 手输 hex

面板语义：点即生效写盘并广播；头部胶囊与菜单色块同步刷新。

4列表实时联动

chevron、文件夹、组名、成员脊线同帧换色；「无颜色」一键回默认。

规格标注

尺寸 · 间距
  • 面板宽 240px（原 200px），内边距 12px
  • 色格 32×32px · 圆角 7px · 间距 6px
  • 底部行高 28px：无颜色按钮 + hex 输入
  • 对话框内色格 30×30px，面板同构
    • 颜色 · 主题
  • 面板底 popup-bg #23262d · 描边 #4a4e59
  • 色板沿用 24 色（18 彩 + 6 中性），明暗主题各一套
  • 选中外环 = 当前色 2px，勾选白色带投影
  • hover = 白 75% 描边 1px offset
    • 行为 · 语义
  • 面板：点即生效（保持现状，无确认步骤）
  • 对话框：暂存草稿，随「创建/保存」提交，可取消
  • hex 输入非法 → 输入框红色描边，不提交
  • Esc / 点空白 = 收面板；再收菜单需再点空白
