聚焦范围：沉浸式标题栏（Windows / Linux，custom-titlebar = true）右上角窗口三键中的 关闭键。鼠标与键盘都能走通全部状态，并覆盖「有活动会话 → 关闭确认」整条链路。 macOS 走原生红绿灯按钮，不在本稿内。
几何与色值全部取自 ui/app.slint（WinBtn / 标题栏）与 ui/theme.slint：键 46×38、图标 16px、三键零间距、 窗口圆角 8px。窗口按真实 1280×720 搭建，面板窄时可横向滚动 （已默认滚到右端，先给你看关闭键）。
确认卡位于窗口正中、采用透明毛玻璃（backdrop-filter: blur(20px)）， 标题为「关闭主窗口」、右上角 × 取消。页末给出逐项实施映射。

落地状态（本轮已实现）：本稿已落到真实代码，不再只是原型。
· 关闭行为已加：config_file.rs 的新字段 + config.rs 的 close_behavior()/set_close_behavior()；设置面板 interface_panel.slint 新增「窗口」页与 ComboBox，与 app.slint 的确认卡双向绑定。
· 确认卡已按本稿重写（四段式 / 卡片即操作 / 底部只留「取消」/ 会话清单可滚动）。
· 系统托盘已真实现——原先判断「代码里没有托盘能力」是对的，但 windows crate 已在依赖里且启用了 Win32_UI_Shell， 只补三个 feature 即可用 Shell_NotifyIconW 落地，未引入新 crate （src/app/tray.rs）。托盘图标按需创建：只有真的「最小化到托盘」 才会出现，没用到该功能时启动外观与改动前完全一致。

毛玻璃在真实应用里打折（唯一的观感缺口）：本稿的磨砂是 HTML backdrop-filter 实现的真模糊，而 Slint 1.16 没有该能力 （已在 i-slint-core / compiler / renderer 源码核实「backdrop」零命中）。 落地的确认卡用不透明 Theme.popup-bg + Theme.modal-scrim 近似： 层级与阴影一致，但身后的终端内容不会被真正模糊。这是平台限制，不是实现取舍。

去掉确认按钮后的取舍：卡片「点哪张就执行哪个」之后，误点「完全退出」会 立即断开全部 SSH 会话，没有第二次确认。补偿手段：破坏性卡片 hover 变红 （close-red）承担预警，非破坏性的「最小化到托盘」排在左侧首位。 若更看重防误触，可改回「先选后确认」两步式——卡片样式两种都能复用。

顺带记录一处文档偏差（未改）：ui/app.slint 的 WinBtn 附近注释写「height 补齐行高（43px）」，但沉浸式标题栏实际是 38px。 本稿与落地代码均以 38px 为准。
