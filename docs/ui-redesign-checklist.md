# 交互重构清单（2026-09-14）

> 本文汇总 2026-09-14 讨论的全部设计决策，按「改动性质」分类，便于评估工作量与优先级。
>
> - **A 类**：交互模型变化 —— 需要重新设计交互
> - **B 类**：视觉调整 —— 交互不变，只改样式
> - **C 类**：既有重复清理 —— 架构层面的合并，消除双入口
> - **D 类**：数据与后端改动

---

## A. 需要重新设计交互（模型变化）

| # | 项 | 现状 | 目标 |
|---|---|---|---|
| A1 | **命令栏位置** | 贴在每个终端底部，每标签一条 | 移到右侧面板，与「运行状态」标签页切换 |
| A2 | **命令栏形态** | 固定内嵌 | 默认嵌面板，可**拆为独立置顶窗口**（复用进程信息窗口外壳），关闭 = 收回面板 |
| A3 | **命令栏目标** | 「所有会话」布尔开关（仅作用于命令栏发送） | **多选频道**（仅当前 / 所有 / A∪B∪C∪D）+ 去重计数 + `发送 → N`。注意：这是**本次发送范围**，与会话的频道归属（单选）无关 |
| A4 | **快捷命令入口** | 底部下拉 + 独立侧栏 | 命令栏面板内的列表（按 group 分段），侧栏形态退役 |
| A5 | **历史命令入口** | 下拉 + `Ctrl+Shift+R` 唤起搜索 | 面板内列表 + **常驻搜索框** |
| A6 | **同步输入开关** | `sync_input`（窗口级）与 `send-to-all`（标签级）两个开关，互不读取 | 统一为**频道模型**：终端输入按当前标签所属频道同步 |
| A7 | **分组颜色** | 无 | 三处入口 + 三处落点（见下表） |
| A8 | **标签溢出** | 横向滚动 | `···` 打开总览列表（分组竖条 + 频道字母徽章） |
| A9 | **标签提示** | 无 | 悬停显示分组名 + 同步频道 |

| 落点 | 表现 |
|---|---|
| 组头折叠箭头 | 跟组色 |
| 组头文件夹图标 | 跟组色 |
| 成员行树线 | 跟组色 |
| **标签底部分组色条** | 跟组色（2px 浮层；激活 100% / 未激活 45%） |

## B. 视觉调整（交互不变）

| # | 项 | 现状 | 目标 |
|---|---|---|---|
| B1 | **标签激活态** | 2px accent 描边 | 背景提亮（`bg-panel-alt`），去描边 |
| B2 | **标签高度** | 30px | **保持 30px 不变** |
| B3 | **标签分组色条** | 无 | **底部 2px 浮层**（绝对定位，不占布局高度）；同组标签底部同色，扫视时成带状 |
| B4 | **标签频道徽章** | 无 | **名称前**显示：实色块 20×16 + 单字母（`A`~`D`）；**不在频道则不出现**；字色 = 主题背景色（自动反色，见 G 节） |
| B5 | **标签关闭键** | 常显 | 未激活 35% 常显，悬停 / 激活升到 90% |
| B6 | **列表状态圆点** | 每行都有（黄/橙） | **只在「已连接」时显示绿点** —— 常态不占信号 |
| B7 | **标签连接圆点** | 每标签常显（绿 / 黄） | **去掉** —— 打开着的标签"已连接"是常态、不占信号；断线时终端内已有整片红字提示 |
| B8 | **分组对话框** | 硬编码 `height: 208px` + `vertical-stretch`、错误位常驻、按钮不等宽、标题 700 | 高度由内容撑开；8px 栅格；错误态（红描边 + 文案，仅出错时占位）；按钮 78×32 等宽；标题 500；打开即聚焦 |
| B9 | **落点空槽框**（会话拖拽） | 四边手拼虚线（段 6px + 隙 6px）；扁框（≈200×36）上横密纵疏、**密度差 5 倍**，且 Slint 手拼虚线**做不出圆角** | **实线圆角框**：组色描边 1px（alpha 0.55）+ 圆角 6px + 淡底 0.06；绘制成本由 128 个小段降到 1 个元素（已实现 · `#slot-box-solid`） |

## D. 数据与后端改动

| # | 项 | 内容 |
|---|---|---|
| D1 | 分组颜色存储 | `HashMap<组名, hex>`；`rename_group` 同步迁移、`delete_group` 清理（否则重命名静默丢色） |

## E. 建议优先级

| 顺序 | 项 | 理由 |
|---|---|---|
| 1 | **分组颜色**（A7 + B3/B6 相关 + D1/D2） | 独立闭环，收益清晰，不依赖频道 |
| 2 | **标签视觉**（B1~B5） | 小改动、立竿见影，且为频道色条铺路 |
| 3 | **状态圆点取舍**（B6/B7） | 极小改动，直接降低噪音 |
| 4 | **对话框重设计**（B8） | 独立，可与 1 合并做（颜色字段本就要加） |
| 5 | **命令栏重构**（A1~A5 + C3 + D4/D5） | 大改动，但可先做「面板形态」，窗口形态随后 |
| 6 | **频道 + 同步合并**（A6 + A3 + C1 + D3/D6） | 最复杂：涉及输入通路重构与两个遗留开关退役 |

## G. 频道色 · 集中定义与引用点

**关键：颜色只在 `theme.slint` 定义一次，所有引用点共用同一组变量 —— 不在每个位置各写两套色值。**

### 定义（`ui/theme.slint`）

```slint
// 频道色：两档跟主题走（深色主题用亮版、浅色主题用深版）
property <color> channel-a: dark ? #F06292 : #C2185B;
property <color> channel-b: dark ? #2196F3 : #1565C0;
property <color> channel-c: dark ? #FB8C00 : #BF360C;
property <color> channel-d: dark ? #43A047 : #2E7D32;
// 色块上的字色 = 主题背景色（深色主题自动配深字、浅色主题自动配白字）
property <color> on-channel: base-bg-root;
```

### 色值明细（全部达 WCAG AA）

| 频道 | 深色主题（亮块 + 深字） | 浅色主题（深块 + 白字） |
|---|---|---|
| A 品红 | `#F06292` — 字 5.51 | `#C2185B` — 字 5.87 |
| B 蓝 | `#2196F3` — 字 5.39 | `#1565C0` — 字 5.75 |
| C 橙 | `#FB8C00` — 字 7.10 | `#BF360C` — 字 5.60 |
| D 绿 | `#43A047` — 字 5.10 | `#2E7D32` — 字 5.13 |

- **字** = 字母压在色块上的对比度（需 ≥4.5）
- **块** = 色块压在标签底上的对比度 4.17~5.80（需 ≥3.0）

### 6 处引用点（全部自动跟主题，无需各自处理）

| # | 位置 | 频道色的用法 |
|---|---|---|
| 1 | **标签的频道徽章** | 色块底色 + 单字母（字色 `on-channel`） |
| 2 | **右键「同步输入」菜单** | 每个频道项前的色点 |
| 3 | **命令栏发送目标** | chip 的色点 + 选中态描边 |
| 4 | **终端顶部横幅** | 左侧色块 + 左边框 |
| 5 | **标签栏同步徽章展开列表** | 每个频道的色点 |
| 6 | **标签悬停浮层** | 「同步输入：频道 A」前的色点 |

**核对要点**：以后新增任何用到频道色的位置，一律引用 `Theme.channel-*`，**不要写死色值**。
